# Extensions and Security

Use this reference when choosing an extension, configuring CSP for generated
styles, or comparing similar URL and JSON helpers.

## Generated styles under CSP

### Apply an inline-style nonce

`inlineStyleNonce` adds a CSP nonce to inline styles generated by htmx.
Configure it before htmx loads. A configuration meta tag can provide the
request-specific nonce:

```html
<meta name="htmx-config" content='{"inlineStyleNonce":"request-specific-nonce"}'>
```

## Attribute mutation

### `attribute-tools`

The `attribute-tools` extension swaps arbitrary attributes on or off through
`attributes` or `data-attributes`.

Use `class-tools` instead for the parallel CSS-class behavior exposed through
`classes` or `data-classes`.

## URL construction

### `path-params`

`path-params` fills path variables from request parameters. It removes consumed
parameters afterward, so they are not also sent in the query string or request
body.

### `dynamic-url`

`dynamic-url` resolves `{varName}` placeholders through a configurable function
or a `window` fallback. Unlike `path-params`, it does not depend on `hx-vals`.

Choose between the two based on whether URL values should come from request
parameters or from dynamic placeholder resolution.

### `replace-params`

`replace-params` changes only selected parameters while preserving all others.
An empty-string value deletes the corresponding parameter.

This is useful for pagination and search changes that should not rebuild the
complete parameter set.

## Client and server cache bypass

### `no-cache`

`no-cache` forces htmx to bypass browser caches and issue a fresh request. It
also sends an `hx-no-cache` header so a cooperating server can bypass its own
cache.

This differs from `getCacheBusterParam`, which separates full-page and fragment
cache variants when an intermediary cannot vary on `HX-Request`.

## JSON form encoding

### `form-json`

`form-json`:

- Preserves number and boolean types.
- Base64-encodes files.
- Builds nested JSON from dot or bracket notation in form control names.

### `json-enc-custom`

`json-enc-custom` supports more complex objects, lists, and indexed structures
encoded through form control names.

Choose the extension whose data model matches the submitted structure rather
than treating the two encoders as interchangeable.

## Extension deployment checklist

- Version extensions independently from core.
- Upgrade the SSE extension when migrating from the removed `hx-sse` form.
- Replace the removed `hx-ws` form with the corresponding extension attribute.
- Prefer extensions when introducing new functionality outside core.
