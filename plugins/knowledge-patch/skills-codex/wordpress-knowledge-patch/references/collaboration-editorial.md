# Collaboration and editorial behavior

## Block notes, mentions, and inline feedback

WordPress 6.9 lets editors attach threaded notes to individual blocks, resolve
or edit them, and notify the post author by email.

WordPress 7.1 expands Notes with mentions and inline feedback, adding
collaboration affordances beyond block-level threaded comments.

## Block visibility

WordPress 6.9 adds block hide and reveal controls. WordPress 7.0 extends these
to device-specific visibility rules exposed in the toolbar, inspector, command
palette, and List View.

## Post-author notification filtering

In WordPress 7.1, the `notify_post_author` filter has final authority over
whether post-author notifications are sent.

## Style Book in Classic themes

WordPress 6.8 makes its streamlined Style Book available in select Classic
themes. Using it no longer necessarily requires a block theme.

## Features deferred from 7.1

The Classic block remains available in the inserter. React 19 remains
experimental outside Core. Real-time collaborative editing is not enabled in
WordPress 7.1.
