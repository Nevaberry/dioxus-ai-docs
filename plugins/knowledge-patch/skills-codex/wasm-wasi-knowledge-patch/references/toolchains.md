# Initial WASI Async Toolchain

## Minimum components (`wasi-0.3-guide`)

For the initial WASI 0.3 release, use:

- Wasmtime 46 or later, where WASI 0.3 and `component-model-async` are enabled
  by default;
- `wit-bindgen` 0.46 or later with its `async` feature; and
- `wkg` 0.15 or later for WASI 0.3 packages.

For JavaScript host bindings, use jco's `preview3-shim`.

## Rust constraint

Initial Rust builds require nightly Rust. Stable Rust bundles a
`wasm-component-ld` that is too old for the WASI 0.3 output generated by
`wit-bindgen` 0.58.

Check runtime, binding-generator, package tooling, host bindings, compiler
channel, and component linker independently when diagnosing compatibility.
