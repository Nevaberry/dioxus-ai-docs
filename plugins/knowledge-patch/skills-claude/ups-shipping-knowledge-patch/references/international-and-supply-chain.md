# International and Supply Chain APIs

## Customs and compliance

### Customs Detail API

Customs Detail supplies current UPS-shipment compliance requirements so
integrations can collect more accurate customs data before submission.

### Global Checkout GraphQL API

Global Checkout is offered as a GraphQL API for obtaining guaranteed
international duty-and-tax quotes at checkout.

Its country, province, and measurement-unit codes are defined in a dedicated
appendix.

### Export and address assurance

Export Assure offers interactive description-of-goods guidance and
destination-specific commodity compliance checks.

DeliveryDefense Address Confidence provides a pre-label address-confidence
score based on delivery data.

## Freight and supply chain APIs

### Supply Chain Solutions ingestion

SCS Inventory synchronizes WMS orders and updates for order and inventory
visibility.

SCS Logistics ingests operational events in near real time.

SCS Transportation sends TMS shipments and updates to the UPS Supply Chain
Symphony datastore.

### Forwarding API

The Forwarding API creates and manages air, ocean, and ground
freight-forwarding shipments billed to a shipper, receiver, or third-party
account.

### TradeDirect API

TradeDirect provides direct international shipping from manufacturers to end
consumers. The Shipping API can create shipments for the product.
