# Extensions and Security

## Add a nonce to generated inline styles

`inlineStyleNonce` applies a CSP nonce to inline styles generated by htmx.
Configure it before htmx loads, for example with the configuration meta tag:

```html
<meta name="htmx-config" content='{"inlineStyleNonce":"request-specific-nonce"}'>
```

## Mutate arbitrary attributes

The `attribute-tools` extension swaps arbitrary attributes on or off through
`attributes` or `data-attributes`. It parallels `class-tools`, which performs
the corresponding operation for CSS classes through `classes` or
`data-classes`.

## Choose between path parameters and dynamic URLs

`path-params` fills path variables from request parameters. It then removes
the consumed parameters so they are not also sent in the query string or
request body.

`dynamic-url` resolves `{varName}` placeholders through a configurable
function or a `window` fallback. It does not depend on `hx-vals`.

## Replace only selected parameters

`replace-params` changes specified parameters while preserving all others. An
empty-string value deletes the corresponding parameter. Use it for operations
such as pagination or search updates that should not rebuild the complete
parameter set.

## Bypass client and server caches

`no-cache` forces a fresh request that bypasses the browser cache. It also
adds an `hx-no-cache` header so a cooperating server can bypass its own cache.

## Choose a structured JSON form encoder

`form-json` preserves numbers and booleans, Base64-encodes files, and builds
nested JSON from dot or bracket notation.

`json-enc-custom` supports more complex objects, lists, and indexed structures
encoded through form control names.
