# Migrations and breaking changes

Use this as a search checklist before changing an older codebase. Read the
platform or topic reference for the full behavioral context.

## Removed project mechanisms and generated artifacts

| Old assumption | Current action | Source |
| --- | --- | --- |
| Imperatively apply Flutter's Android Gradle script | Use declarative Gradle plugin application | 3.29.0 |
| Android v1 embedding Java APIs | Migrate applications and plugins to v2 embedding | breaking-change-guides |
| Select the Flutter web HTML renderer | Use a remaining Skia-backed web renderer | 3.29.0 |
| Depend on `package:flutter_gen` | Import generated localization source from its real output | 3.32.0 |
| Build or capture iOS SkSL warm-up data | Remove the SkSL target and bundled-data workflow | 3.32.0 |
| Read SDK root `version` | Read `bin/cache/flutter.version.json` | 3.38-guide |
| Read `.flutter-plugins` | Read `.flutter-plugins-dependencies` | 3.35.0 |
| Assume `AssetManifest.json` exists | Use supported asset APIs; it is not generated by default | 3.38-guide |
| Set `pluginClass: none` or `dartPluginClass: 'none'` | Omit the corresponding key | 3.35-guide, 3.38.0 |
| Generate Objective-C or `plugin_ffi` templates | Use Swift Apple plugins and the standard plugin template with FFI | 3.38.0, 3.44-guide |

## CLI migrations

| Removed or old form | Replacement | Source |
| --- | --- | --- |
| `dart format --fix` | `dart fix` | dart-3.7.0 |
| `--web-experimental-hot-reload` enablement | Default stateful web hot reload; remove stale enablement | 3.35-guide |
| `--web-hot-reload` | Current web reload workflow | 3.44-guide |
| `flutter assemble --define` / `-d` | `--dart-define` / `-D` | 3.38.0 |
| `--disable-dds` or `--no-disable-dds` | `--no-dds` | 3.38.0 |
| `--fast-start` | Remove it | 3.38.0 |
| Global Widget Preview `--dtd-url` | Pass it to `widget-preview start` | 3.38.0 |
| `dart build -f exe <target>` preview | `dart build cli --target=<target>` | dart-3.9.0 |
| `--pwa-strategy` | Remove service-worker strategy dependence | 3.41.0 |

`flutter build` without a target exits with status 1. Chrome-device launches no
longer inject `--no-sandbox` (3.41.0).

## Dart and package migrations

- Run `dart pub get` after changing the SDK constraint and before formatting, so
  `package_config.json` selects the intended formatter language version
  (dart-3.7.0).
- Migrate `dart:html`, `dart:indexed_db`, `dart:js`, `dart:js_util`,
  `dart:web_audio`, and `dart:web_gl` to `dart:js_interop` and `package:web`
  (dart-3.7.0).
- Declare imported packages directly. Explicit dependency checking became default
  in 3.32.0 and unconditional in 3.35.0.
- For a language-3.9 root, expect Pub to enforce the upper
  `environment.flutter` bound (dart-3.9.0).
- Do not plan code generation around Dart macros; that effort was cancelled
  (dart-language-roadmap).

## Framework API migrations

| Old API or pattern | Replacement or behavior | Source |
| --- | --- | --- |
| Implement `PipelineOwner` | Extend the `base` class with an allowed subclass modifier | 3.32.0 |
| `CupertinoButton.minSize` | Independent `minWidth` and `minHeight` | 3.32.0 |
| `Tooltip.height` | `Tooltip.constraints` | 3.32.0 |
| `ExpansionTileController` | `ExpansibleController` | 3.32-guide |
| Per-widget radio `groupValue` / `onChanged` | A surrounding `RadioGroup` | 3.35-guide |
| `DropdownButtonFormField.value` | `initialValue` | 3.35-guide |
| Direct `Form` sliver | Wrap the form in `SliverToBoxAdapter` | 3.35-guide |
| `Switch.activeColor` | `activeThumbColor` | 3.35.0 |
| `AppBarTheme.color` | `backgroundColor` | 3.35.0 |
| `OverlayPortal.targetsRootOverlay` | `OverlayPortal` with `OverlayChildLocation.rootOverlay` | 3.38-guide |
| `CupertinoDynamicColor.withAlpha/withOpacity` | Standard `Color` methods | 3.38-guide |
| Per-property `Expansible` animation config | `AnimationStyle` | 3.41.0 |
| Nullable `DropdownMenu<T>` type | A non-nullable generic type | 3.41.0 |
| Assign `sceneLifeCycleDelegate` | Stop assigning; the property is read-only | 3.41.0 |
| Cupertino sheet `builder` / `pageBuilder` | `scrollableBuilder` | 3.44-guide |
| `ReorderableListView.onReorder` | `onReorderItem` with removal-adjusted `newIndex` | 3.44-guide |
| `findChildIndexCallback` in separated lists | `findItemIndexCallback` | breaking-change-guides |
| `InputDecoration.maintainHintHeight` | `maintainHintSize` | breaking-change-guides |
| Subclass `IconData` or `TextDecoration` | Use an instance or composition | 3.44.0 |
| `ExtendSelectionByPageIntent` | Remove callers; the intent is gone | 3.44.0 |
| `ImageFilterConfig.blur(bounded: ...)` | Remove `bounded` | 3.44.0 |

Removing a route now calls `didComplete` (3.32.0). Audit route futures and custom
lifecycle code that assumed `Navigator.removeRoute` did not complete.

The close-callback order for `RawMenuAnchor` changed (3.44-guide). Treat callback
order as the new contract rather than retaining old sequencing.

## Theme migrations

- `ThemeData.dialogBackgroundColor` becomes
  `DialogThemeData.backgroundColor` (3.29.0).
- `ButtonStyleButton.iconAlignment` moves to `ButtonStyle.iconAlignment` or
  `styleFrom` (3.29.0).
- `ThemeData.indicatorColor` becomes
  `TabBarThemeData.indicatorColor` (3.32-guide).
- `cardTheme`, `dialogTheme`, and `tabBarTheme` take their `...ThemeData` value
  types (3.32-guide).
- Remaining component theme values, including app bar, bottom app bar, and input
  decoration, use `...ThemeData` types (3.35-guide).

The Material and Cupertino libraries are moving from the framework to independently
versioned `material_ui` and `cupertino_ui` packages (3.44-guide). Do not mix the two
distribution models without checking the selected SDK and package constraints.

## Behavioral changes to retest

- A `SnackBar` with an action no longer auto-dismisses (3.38-guide).
- `MaterialApp` defaults to predictive-back-aware fade-forwards transitions instead
  of zoom transitions (3.38-guide).
- `FontWeight` affects variable-font weight axes starting in Flutter 3.41
  (breaking-change-guides).
- Flutter 3.44 emits a debug error for a colored wrapper around `ListTile`
  (breaking-change-guides).
- `DropdownButton.enabled` is independent of whether `onChanged` is provided
  (breaking-change-guides).
- `ImageFilter.blur` chooses its tile mode when omitted; set one explicitly for
  fixed edge sampling (breaking-change-guides).
- Android defaults to edge-to-edge system UI and later large-screen releases ignore
  orientation/resizability restrictions (breaking-change-guides).
- Mobile UI/platform thread merging is mandatory (3.38-guide).
- Android tooling retains native symbols in `libapp.so` (3.44.0).

## Migration verification

1. Search source, scripts, CI, platform projects, and custom build tooling for every
   old name or artifact relevant to the project.
2. Apply mechanical fixes first, then inspect behavior changes separately.
3. Run analysis and tests across affected platforms, renderers, accessibility
   settings, keyboard/pointer modes, navigation paths, and build flavors.
4. Inspect Gradle, Xcode, SwiftPM, asset, shader, plugin-metadata, and CLI warnings.
