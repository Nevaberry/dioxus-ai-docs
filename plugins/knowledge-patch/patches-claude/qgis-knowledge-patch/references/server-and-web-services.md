# Server and web services

Use this reference for QGIS Server configuration and recovery, WMS/WFS/OAPIF
request behavior, OAuth2 token handling, temporal service metadata, and
GetFeatureInfo output.

## Temporal controls for WMS-T groups and rasters (since 3.44)

WMS-T layer-tree groups recursively compute and expose a time dimension from
their children. Disabling the option on a group also stops its children's
dimensions from propagating to the parent. Group dimensions can contain OGC
WMS/ISO 8601 date ranges. A raster layer can use one fixed date/time to infer
both ends of its temporal range.

## Extra OAuth2 tokens as headers (since 3.44)

Advanced OAuth2 configuration can attach additional tokens returned by the
token endpoint as HTTP(S) request headers for any OAuth2 service.

## Configurable server project cache (since 3.44)

`QGIS_SERVER_PROJECT_CACHE_SIZE` configures the QCache cost used by the server
project cache instead of relying on the former hardcoded value.

## Server metadata on layer-tree groups (since 3.44)

Layer-tree groups can publish keywords, a data URL and format, attribution
title and URL, metadata URLs, and a legend URL and format through
GetCapabilities, in addition to short name, title, and abstract. When no legend
URL is set, a legend is generated by default.

## OAuth2 token auto-refresh (since 4.0)

OAuth2 connections refresh tokens automatically while in use. Periodic cleanup
and layer removal stop refresh activity for unused connections.

## HTML GetFeatureInfo maptip-only mode (since 4.0)

A project-level setting can make HTML GetFeatureInfo use only the layer maptip.
It corresponds to the WMS vendor parameter
`WITH_MAPTIP=HTML_FI_ONLY_MAPTIP`.

## Retrying invalid QGIS Server layers (since 4.0)

Set `QGIS_SERVER_RETRY_BAD_LAYERS=true` to retest layers previously accepted as
bad on every request and return them to service after their dependency
recovers. Account for the per-request retry cost when dependencies stay down.

## Mesh GetFeatureInfo responses (since 4.0)

QGIS Server can answer GetFeatureInfo requests for mesh layers.

## Changed OAPIF server root (since 4.0)

The default QGIS Server OAPIF root is `/ogcapi`, replacing `/wfs3`. Set
`QGIS_SERVER_API_WFS3_ROOT_PATH` when another path is required. Update public
proxy routes, generated links, client configuration, and tests consistently.

## WMS highlight label frames (since 4.2)

QGIS Server WMS requests can style highlight-label frames with
`HIGHLIGHT_LABELFRAMEBACKGROUNDCOLOR`,
`HIGHLIGHT_LABELFRAMEOUTLINECOLOR`,
`HIGHLIGHT_LABELFRAMEOUTLINEWIDTH`, and `HIGHLIGHT_LABELFRAMESIZE`. Parameters
can be scoped to a map, for example `MAP0:HIGHLIGHT_LABELFRAMESIZE=5`.

## FlatGeobuf OAPIF export (since 4.2)

QGIS Server's OGC API Features service can export FlatGeobuf.
